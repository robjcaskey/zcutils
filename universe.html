How the layers fit

descriptor primitives -> streams -> WALs -> volumes -> SAN
                                                         -> Kubernetes CSI adapter
                                                         -> clients without Kubernetes

The CSI adapter translates Kubernetes requests. Storage policy and data movement belong to the underlying userspace storage services. The zccusan architecture describes the full layering.

Find your deployment path

zccusan with Kubernetes covers CSI, Helm, cluster policy and workload storage. zccusan without Kubernetes covers the underlying services, direct interfaces and current standalone limits. Both paths may use physical servers, virtual machines or cloud instances.
