# Apple-generated DriverKit interfaces

These files were generated with Apple iig from the two project `.iig` files,
using Xcode 16.4 and DriverKit SDK24.5. They are build inputs; do not edit them.
Each architecture manifest fingerprints the inputs, SDK, generator and outputs.
The SDK itself is not stored here. Routine builds verify the cache without iig.

Generation and Apple native compilation for both architectures passed in
[manual run39659941491](https://github.com/robjcaskey/zcutils/actions/runs/39659941491).
Linux Clang19 builds, Mach-O structure comparisons and Mac signature-integrity
checks also passed. Native extension activation/mounting is not verified.
See [the build instructions](../../../docs/native-desktop-builds.md#cached-driverkit-interfaces-and-linux-builds).
