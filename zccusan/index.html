Diskpipe

Diskpipe is high-performance storage for your Kubernetes cluster: multi-user, multi-tenant, multi-region, and rate-limited, designed for low unit costs and delivering 75 GB/s on a two-node cluster, with room to scale from there.

The implementation currently lives under zccusan/ in the zcutils repository. Binary names, API paths and installation commands retain their existing names.

Operate the storage system

Day-two identity and failover covers scoped OAuth, IAM and native Kubernetes identity, supplementary approval, workload failover and cleanup. Each deployment page points to the relevant installation and architecture material.

The architecture reference defines the shared storage layers. The Kubernetes CSI adapter translates requests; the storage services own placement, replication and tenancy.
